# Hryzen Studios Documentation

Documentation for all Hryzen Studios FiveM resources.

If you're confused or need more help, feel free to open an issue or discussion on the relevant resource's [GitHub repo](https://github.com/Hryzen-Studios).

## Resources

- [hryzen_lib](/hryzen-lib/intro) — Free framework bridge SDK used by every Hryzen resource; supports QBX, QBCore, and ESX.
- [hryzn_spawn](/hryzn-spawn/intro) — Stylised spawn selector for QBX Core, drop-in replacement for `qbx_spawn`.
